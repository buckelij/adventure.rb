Quick reference

Algorithm
A set of steps for solving a problem, like a recipe.
Conditional statement
A choice in a program: do something if a condition is true.
Function
A named set of steps you can ask the computer to do. In Ruby, these are often called methods.
Input
Information given to a program, like an answer typed with gets.
Loop
Instructions that repeat. A loop can keep going until you tell it to stop.
Output
Information a program shows you, like words printed with puts.
String
A piece of text, usually written between quote marks, like "hello".
Variable
A named place to keep information, like score = 10.
